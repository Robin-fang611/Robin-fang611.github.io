## 4. 人工评审 · AI 味八项

1. **比例**：六档字阶比率 1.29–1.32；标题 1.1 行高，正文 1.8；印章/按钮统一 2px 圆角；箭头与正文同视觉重量。通过。
2. **节奏**：章节 64px 上下、条目 24px、细线分隔；正文、目录、案例结果列三条主对齐线，另有三条由印章与联系栏产生，共 6 条，在阈值内。通过。
3. **色彩**：3 个色相、10 个色值；朱砂只出现在印章、关键数字、当前章节、链接；无渐变、无脏阴影、无第四种颜色。通过。
4. **字体**：2 族、3 字重；宋体标题 + 黑体正文的中英混排经过字距调整（标题 -0.01em，标签 0.12em）；无网络字体。通过。
5. **动效**：仅墨线（600ms）、悬停（180ms）、印章静态微旋；全部 ease-out；减少动效模式关闭。通过。
6. **内容**：所有数字带口径与时间；客户脱敏；自述数字标「本人记录 / 客户口径」；删除玩家数、未核实的「4 个物流项目」；无「赋能 / 一站式 / 闭环生态」。通过。
7. **结构**：三档深度、三层层级（章 → 条目 → 要点）；密度在摘要（案例）与履历（列表）之间变化；右侧留白作为材料页的外边距。通过。
8. **完成度**：hover / focus-visible / active / 当前章节 / 复制成功与失败 / dialog / 折叠 / 无 JS / 打印 / 减少动效齐全；加载与空数据场景不适用。通过。

## 5. 结论

新版把「可核对」做成了界面结构：参数收敛、对比度全过、状态齐全、中英同源。视觉上从「水墨氛围」转为「卷宗材料」，记忆点由三件东西承担：封面右上角的朱砂大印、每章编号小印、标题下的手写墨线。
