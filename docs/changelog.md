# 变更日志

## v2.0 · 2026-10-21 — 卷宗版

### 结构

- 站点从「单文件 HTML ×2」改为「内容单源 + 渲染层 + 静态生成」：`src/content/site.mjs` → `src/render/page.mjs` → `build.mjs` → `index.html` / `en/index.html`。
- 信息架构按访客决策路径重排为三档深度：封面 + 01 摘要（60 秒）→ 02 证据 / 03 履历 / 04 生态（2–3 分钟）→ 05 方法 / 06 议题（10 分钟）→ 07 联系。
- 新增常驻目录（桌面左栏 / 移动端原生 `<dialog>`）、阅读进度线、当前章节标记。
- 删除旧版 470vh 的钉住 + 帘幕转场、鼠标拖尾、滚动底色插值、数字滚动、Lenis 平滑滚动。

### 视觉

- 设计语言从「水墨氛围」改为「卷宗材料」：纸 `#F4F0E7`、墨 `#1C262E`、朱砂 `#9B3A2C`；宋体标题 + 系统黑体正文；2px 圆角；细线分隔。
- 字阶收敛到 6 档（17/22/29/38/50/66），间距 10 档（8–128），色相 3 个。
- 新增：封面朱砂大印、章节编号小印、手写墨线、OG 分享图（1200×630）、SVG favicon、404 页。
- 删除 CDN 依赖：Google Fonts、jsDelivr（霞鹜文楷、Lenis）全部移除；改用系统字体。

### 内容

- 以 2026-10 的可核对事实重写：Linkathon 1,700+（原 1,600+）、社群 3 天 400 / 4 周 1,000、Steam 好评 100%（10 篇评测，样本有限）、美食地图 832 家（2026.08 快照）。
- 撤下无出处的数字：玩家 2,500+、「4 个物流场景 FDE 项目」、单场 200+ 报名。
- 按本人要求，全文不再使用 FDE 表述；保留「驻场交付 / AI 落地」的事实描述。
- 客户名称脱敏为「华南某国际货代」；云天远略（深圳）作为交付主体保留。
- 新增「公开仓库」小节（world-sage / vision-bridge-hook / wuhan-food-map / echoes-of-yesterday）。
- 中英共用一份数据；英文为翻译，不是第二套叙事。

### 工程

- 零依赖构建；`npm run build` 产出全部页面与静态文件。
- 运行时 3.5KB：进度线、当前章节、目录弹层、复制邮箱、语言切换保留锚点。
- 渐进增强：无 JS 时内容完整可读，锚点、折叠、mailto 可用。
- 无障碍：跳过导航、单一 h1、`aria-current`、`aria-live`、44px 触控目标、可见焦点、减少动效、打印样式。
- 删除 `en.html`（被 `/en/` 取代），新增 `.nojekyll`、`robots.txt`、`sitemap.xml`。

### 遗留

- GitHub Profile 的 bio 需要在 Settings 手动更新（当前 token 无 `user` scope）。
- 同创教育的 150 万 GMV 仅有本人记录，页面已标注「本人记录」，建议补第三方凭据或降权。
