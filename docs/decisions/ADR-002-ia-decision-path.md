# ADR-002 · 信息架构按「访客决策路径」重排

- 日期：2026-10-21
- 状态：已采纳

## 背景

旧版按作者的经历顺序排版：关于 → 战绩 → 经历 → 合作 → 校内 → 方法 → 思考 → 联系。开头还有 470vh 的钉住 + 帘幕动画，访客要滚过两屏氛围才能看到第一个可判断的事实。

## 决定

把页面当一份尽调材料，按读者的判断顺序排，并分成三档深度：

| 档 | 内容 | 读者时间 |
|---|---|---|
| 一档 | 封面 + 01 摘要（三份证据：问题 → 做法 → 结果） | 60 秒 |
| 二档 | 02 证据（6 条数字，带口径）+ 03 履历 + 04 生态 | 2–3 分钟 |
| 三档 | 05 方法 + 06 议题 | 10 分钟 |
| 行动 | 07 联系（合作 / 工作 / 社群三条分叉） | 30 秒 |

- 每章有编号、锚点、目录项；左栏目录常驻（桌面），移动端收进原生 `<dialog>`。
- 「方法 / 议题」下沉到履历之后，不再抢首屏。

## 取舍

- 得到：首屏就能回答「是谁 / 做过什么 / 怎么联系」；深看的人仍有材料可翻。
- 放弃：按时间线的自传式叙事；部分旧的「校内」「合作伙伴」被并入生态章。

## 后果

- 新增内容必须先回答它属于哪一档、替读者完成什么判断。
- 三份证据的任何改动都会同时影响摘要与首屏事实，需同步。
