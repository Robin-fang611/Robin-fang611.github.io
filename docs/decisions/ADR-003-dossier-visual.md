# ADR-003 · 视觉从「水墨氛围」改为「卷宗材料」

- 日期：2026-10-21
- 状态：已采纳

## 背景

旧版用宣纸、墨环、帘幕、鼠标拖尾、底色渐变营造水墨氛围。它成立，但氛围先于信息：访客先被要求感受，再被要求判断。而 Robin 的可信度来自「驻场、核对基线、拿材料说话」——视觉应该表达这个方法。

## 决定

把页面做成一份被装订的尽调材料：

- 纸：`#F4F0E7` 暖纸底 + 极低对比纤维颗粒。
- 墨：`#1C262E` 文字，宋体承担标题与数字，黑体承担正文。
- 朱砂：`#9B3A2C` 是页面唯一的饱和色，只用于印章、关键数字、当前章节。
- 章节编号做成朱砂方印（01–07），封面右上角一枚大印。
- 首屏标题下保留一道手写墨线（从旧版延续的唯一动效遗产）。
- 版式：左栏目录 + 680px 正文 + 右侧留白；只用细线分隔，不用卡片。

## 取舍

- 得到：可核对、可打印、有材料感；与 GitHub Profile 的「证据」叙事一致。
- 放弃：墨环、帘幕、鼠标拖尾、底色分场——这些只制造氛围，不承载判断。
- 风险：整体偏冷静。用内容的具体性（客户、数字、出处）和朱砂印提供温度。

## 后果

- 新增组件必须能用「纸 / 墨 / 朱砂」解释；不允许引入新色相。
- 打印样式是产品的一部分，不是附加项。
