# ADR-004 · 动效只做增强，内容默认可见

- 日期：2026-10-21
- 状态：已采纳

## 背景

旧版每帧重写 body 背景色、18 个面板的 transform、7 个鼠标拖尾点，即使页面静止也在跑 `requestAnimationFrame`；`.rv` 元素初始 `opacity: 0`，内容可见性依赖 IntersectionObserver。JS 失败或用户快速滚动时，页面会出现空白。

## 决定

- 删除滚动入场、数字滚动计数、平滑滚动劫持、鼠标跟随、视差。
- 保留三处动效：首屏墨线书写（600ms，加载一次）、链接/箭头悬停（180ms）、印章静态微旋（-3°）。
- 内容默认可见；`.js` 类只用于隐藏移动端目录按钮等增强项。
- 关闭 JS：锚点、`<details>` 折叠、`mailto:` 全部可用。

## 取舍

- 得到：内容不依赖 JS；无持续 rAF；`prefers-reduced-motion` 下几乎零动效。
- 放弃：滚动叙事的戏剧性。改用版式与朱印承担记忆点。

## 后果

- 任何新动效必须回答「它帮助读者完成什么判断」，且 <600ms。
- 不允许以 `opacity: 0` 作为初始状态承载正文。
