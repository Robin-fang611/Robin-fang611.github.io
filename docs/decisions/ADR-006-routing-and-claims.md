# ADR-006 · 路由、语言与数字口径

- 日期：2026-10-21
- 状态：已采纳

## 背景

旧版是 `index.html` + `en.html` 两个独立文件，各 40KB，事实容易漂移；数字（1,600 / 2,500 玩家 / 4 个 FDE 项目 / 832 商户）在站点、README、简历之间口径不一，且部分没有出处。

## 决定

### 路由与语言

- 中文：`/`；英文：`/en/`。用路径而不是 `?lang=` 或 hash，便于分享与 SEO。
- 两个页面由同一个 `renderPage(locale)` 生成；语言切换链接自动带上当前 `#章节`。
- 每页有 `hreflang`、`canonical`、双语 OG。

### 数字口径

- 每个数字必须写成「数值 + 口径 + 时间」，并在「出处」行给出来源。
- 只在简历/自有材料出现的数字，标注「本人记录」或「客户口径」。
- 客户名称脱敏为「华南某国际货代」；不在公开页面写客户全名。
- 不写无法核对的数字：玩家数、Steam 在线、未确认的「4 个物流项目」全部撤下。
- 社群规模用最新可核对值（1,700+，2026.10），不再沿用简历里的 1,600+。
- 「100% 好评」必须带「10 篇评测，样本有限」。

### 与 GitHub Profile 的关系

- README 是站点「摘要章」的压缩版，共用同一套事实；改数字先改 `site.mjs`，再同步 README。

## 后果

- 新增数字需同时提供来源与时间，否则不上页面。
- 英文页不是另写一套叙事，而是同一事实的翻译；不允许两边数字不同。
