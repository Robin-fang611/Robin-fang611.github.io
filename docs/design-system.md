# 设计系统：卷宗（Dossier）

> 所有视觉值以此为准；代码里出现文档之外的字号、间距、颜色即为缺陷。
> 实现：`src/styles/*.css` → 构建拼成 `/assets/site.css`

---

## 1. 设计命题

一份被装订起来的尽调材料：**纸、墨、朱印，三种材料，一个判断**。纸负责安静，墨负责层级，朱砂只负责「这里需要你注意」。

- 参照系：年报 / 尽调材料 / 出版物版式；不参照 SaaS 落地页。
- 记忆点：每章一枚朱砂编号印；首屏标题下一道手写墨线。
- 禁止：玻璃拟态、渐变按钮、彩色卡片、图标堆砌、圆角胶囊、深色模式切换。

## 2. Token

### 2.1 颜色（13 个值，3 个色相簇）

| Token | 值 | 用途 | 对比度 |
|---|---|---|---|
| `--paper` | `#F4F0E7` | 页面底色 | — |
| `--paper-2` | `#EAE4D5` | 证据/履历的分场底 | — |
| `--ink` | `#1C262E` | 正文、标题 | 13.5:1 on paper |
| `--ink-2` | `#3A464F` | 次级正文 | 8.5:1 |

| `--accent` | `#9B3A2C` | 朱砂：印章、数字、当前章节 | 6.1:1 |

| `--on-accent` | `#FBF6EC` | 朱砂底上的字 | 6.4:1 on accent |
| `--dark` | `#172027` | 联系章（墨池） | — |
| `--on-dark` | `#EDE8DB` | 墨池上的正文 | 13.5:1 |

| `--dark-line` | `rgba(237,232,219,.18)` | 墨池分割线 | — |

色相：纸 44°、墨 207°、朱砂 8°。没有第四个色相。语义色不另设——朱砂即强调，墨即信息。

### 2.2 字体（2 族）

```css
--font-serif: "Songti SC", "STSong", "Noto Serif SC", "SimSun", serif;
--font-sans: -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif;
```

- 标题、数字、印章：宋体（serif），字重 700
- 正文、标签、按钮：黑体（sans），字重 400 / 600
- 英文页通过 `html[lang="en"]` 把标题族换成 `"Iowan Old Style", Palatino, Georgia`，避免宋体拉丁字形在英文长标题里显得生硬；中文页仍用宋体。
- 不使用等宽字体；数字用宋体的等比数字，靠字号与对齐承担「表格感」
- 不加载网络字体：国内访问 Google Fonts / jsDelivr 不可靠，系统字最快也最稳

### 2.3 字阶（6 档，比率 ≈1.31）

| Token | 桌面 | 移动 | 用途 |
|---|---|---|---|
| `--fs-1` | 17px | 16px | 正文、目录、按钮 |
| `--fs-2` | 22px | 20px | 导语、案例标题、联系项 |
| `--fs-3` | 29px | 26px | 章节序号、列表主标题 |
| `--fs-4` | 38px | 30px | 章节标题、关键数字 |
| `--fs-5` | 50px | 38px | 联系章标题、超大数字 |
| `--fs-6` | 66px | 44px | 首屏 h1 |

行高：`--lh-tight: 1.1`（展示）/ `--lh-title: 1.25`（标题）/ `--lh-body: 1.8`（中文正文）/ `--lh-snug: 1.5`（短句）。
字距：`--ls-title: -0.01em`；`--ls-label: 0.16em`（小标签全大写/拉开）。

### 2.4 间距（9 档，4 的倍数）

`8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128`（4px 只用于箭头微位移，不参与版式）

- 章节上下留白：`128`（桌面）/ `96`（移动）
- 条目上下：`32`
- 行内元素：`8`、`12`
- 容器左右：`64`（桌面）/ `24`（移动）

### 2.5 其他

- 圆角：`0`、`2px`（仅印章与按钮）——纸是裁切的，不是圆润的
- 阴影：仅 1 种 `--shadow: 0 16px 40px -24px rgba(28,38,46,.45)`，只给弹出目录
- 描边：`1px`（细线）、`2px`（焦点环、当前章节标记）
- 动效：`--ease: cubic-bezier(.2,.7,.2,1)`；`180ms`（悬停）、`320ms`（面板）、`600ms`（墨线）
- 版心：`--page: 1104px`；`--rail: 176px`；`--gutter: 48px`；正文单行宽 `680px`

## 5. 状态清单

| 场景 | 表现 |
|---|---|
| 悬停 | 链接下划线由左展开；按钮底变 `--accent-2`；案例序号变朱砂 |
| 焦点 | `:focus-visible` 2px `--accent` 外环，offset 3px；跳过导航链接首帧可见 |
| 当前章节 | 目录项朱砂 + 左侧 2px 竖线；`aria-current="true"` |
| 复制邮箱成功 | 按钮文案 → 「已复制」，`aria-live="polite"`；2 秒后复原 |
| 复制失败 | 文案 → 「复制失败，请手动选择」，保留可选中文本 |
| 折叠展开 | `<details>` 原生；`summary` 箭头 180° 旋转 |
| 目录弹层 | 原生 `<dialog>`；ESC / 点遮罩 / 点链接关闭；打开时锁滚动 |
| 减少动效 | `prefers-reduced-motion` 关闭墨线与过渡 |
| 打印 | 隐藏导航/目录/按钮；墨色转黑；分章不跨页断开 |
| 无 JS | 内容完整可见；锚点、折叠、mailto 均可使用；复制按钮退化为 mailto |

> 加载态与空态：本站为静态文档，无异步列表，不存在加载/空数据场景；唯一异步动作是复制邮箱，已实现成功与失败两态。

## 6. 动效规范

| 名称 | 触发 | 时长/曲线 | 目的 |
|---|---|---|---|
| 墨线书写 | 首屏加载一次 | 600ms `--ease`，延迟 200ms | 把视线带到 h1 的最后四个字 |
| 链接下划线 | hover | 180ms `--ease` | 确认可点 |
| 箭头位移 | hover | 180ms | 方向暗示 |
| 印章微旋 | 静态 -3° | — | 手盖的痕迹 |
| 目录弹层 | 打开 | 180ms 淡入 + 8px 上移 | 空间关系 |

禁止：滚动入场、数字滚动、视差、鼠标跟随、平滑滚动劫持、超过 600ms 的动画。

## 7. 无障碍与性能预算

- 语义：`header / nav / main / section[aria-labelledby] / footer`；每页 1 个 h1；标题不跳级。
- 键盘：跳过导航 → 顶栏 → 目录 → 正文 → 联系；`<dialog>` 原生焦点管理。
- 触控：所有可点区域 ≥44×44（用 padding 撑开）。
- 对比度：正文 ≥4.5:1，大字（≥24px）≥3:1；已逐项核算（见 §2.1）。
- 键盘焦点始终可见；`aria-live` 播报复制结果。
- 预算：CSS ≤ 24KB，JS ≤ 6KB，无字体请求，首屏 ≤ 4 个请求（HTML + CSS + JS + favicon），LCP < 1.5s。实测 CSS 20.2KB、JS 3.5KB。

## 8. 组件与 token 的边界

- 允许在组件内使用的：`--fs-*`、`--lh-*`、`--ls-*`、`--s*`、颜色 token、`--r`、`--ease`、`--dur-*`。
- 不允许：任意 px 值（除非 1px 描边、2px 焦点环、100%/vh 之外的单位）、新颜色、新阴影、新字体。
- 媒体查询只切换 token（字号、容器间距、列数），不在查询里写死新尺寸。
